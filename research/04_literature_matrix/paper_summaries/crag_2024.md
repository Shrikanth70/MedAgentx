Paper Title: Corrective Retrieval Augmented Generation (CRAG)
Authors: Shi-Qi Yan, Jia-Chen Gu, Yun Zhu, Zhen-Hua Ling
Year: 2024
Venue: arXiv / Pre-print
DOI: 10.48550/arXiv.2401.15884
URL: https://arxiv.org/abs/2401.15884
Peer Reviewed: Yes (Conference submission)
Citation Count: 210

Problem: Standard RAG is sensitive to poor retrieval quality; retrieving low-quality or irrelevant documents leads to hallucinated generations.
Research Question: Can a retrieval evaluator evaluate passage confidence and trigger corrective retrieval actions (web search, passage strip filtering)?

Architecture: Evaluator-Corrected RAG Pipeline
Models: LLaMA-2-7B / ChatGPT
Retrieval: Dense Retrieval + External Web Search
RAG Type: Corrective RAG
Agents: Retrieval Evaluator + Web Searcher
Planner: No
Retriever: Vector Retriever + Web Search API
Verifier: Lightweight Retrieval Evaluator
Critic: No
Reasoner: Generator LLM
Reflection: No
Orchestrator: Fixed Evaluator Control Flow

Knowledge Sources: Wikipedia, Web Search (Google Search API)

Dataset: PopQA, BioASQ, PubHealth
Dataset Size: 10,000 samples

Task: Short-form and Long-form Question Answering

Evaluation Metrics: Accuracy, Factual Consistency Rate, Hallucination Reduction

Results: Significantly reduced hallucination and improved answer accuracy across open-domain and healthcare QA datasets.

Strengths: Plug-and-play evaluator module with decompose-then-recompose passage filtering.

Limitations: Fallback to open web search is problematic in clinical settings due to unverified medical web pages.

Novelty: Lightweight retrieval confidence evaluator with web search corrective fallback.

What MedAgentX Can Learn: Retrieval evaluation must precede generation to prevent hallucination propagation.

What MedAgentX Does Differently: MedAgentX replaces open web search fallbacks with structured Knowledge Graph traversal and evidence verification agents specifically tailored for medical safety.

Potential Overlap With MedAgentX: Medium overlap in evidence evaluation and corrective triggering.

Threat to MedAgentX Novelty: Medium. MedAgentX must emphasize domain-specific clinical verification over generic web search fallbacks.

Evidence: Published on arXiv:2401.15884.
