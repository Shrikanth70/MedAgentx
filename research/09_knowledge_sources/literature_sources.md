# 09 Literature & Knowledge Graph Sources

## Biomedical Literature Sources
- **PubMed Open Access Subset:** Over 4 million articles available via FTP / API for text mining.
- **PubMed API (Entrez E-utilities):** Dynamic retrieval tool for PubMed abstracts.

## Medical Knowledge Graph Ontologies
- **MeSH (Medical Subject Headings):** Hierarchical vocabulary tree for biomedical indexing.
- **SNOMED-CT Clinical Terms (Core Subset):** Standardized clinical terminology.
- **UMLS Metathesaurus:** Cross-ontology mapping linking MeSH, SNOMED, and ICD-10.
